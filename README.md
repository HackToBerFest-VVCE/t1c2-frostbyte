# DataLens — AI-Powered Natural Language Data Analytics

DataLens is an open-source AI-powered platform designed to simplify data analysis using natural-language questions.
It aims to help users explore datasets and discover meaningful insights without requiring advanced SQL knowledge.
The project uses Snowflake datasets and Snowflake CoCo for data exploration and AI-assisted analysis.
DataLens aims to present data insights through clear answers, summaries, and visualizations.
Developed by Team FrostByte for Challenge 02: Best Open-Source AI Project with Snowflake.
