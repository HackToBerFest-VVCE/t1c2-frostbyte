# DataLens Live — AI-Powered Natural Language Snowflake Analytics

> **Developed by Team FrostByte for Challenge B: Best Open-Source AI Project with Snowflake.**

DataLens Live is an open-source, real-time analytics platform designed to simplify data exploration using natural-language questions without requiring advanced SQL knowledge. It connects Streamlit directly to **Snowflake** (`SNOWFLAKE_SAMPLE_DATA.TPCDS_SF10TCL` / `TPCDS_SF100TCL`) and pairs it with a locally hosted **Qwen3-4B** model via Ollama to deliver dynamic business intelligence, interactive visualizations, and plain-English insights without synthetic or simulated data.

## 🛠️ Technology Stack

- **Frontend & App Framework**: [Streamlit](https://streamlit.io/)
- **Data Warehouse Connector**: [Snowflake Python Connector](https://docs.snowflake.com/en/developer-guide/python-connector/python-connector) (`snowflake-connector-python[pandas]`)
- **Local Large Language Model**: [Qwen3-4B](https://ollama.com/) running locally via [Ollama](https://ollama.ai/) (`http://localhost:11434`)
- **Data Manipulation**: [Pandas](https://pandas.pydata.org/) & [PyArrow](https://arrow.apache.org/)
- **Interactive Visualizations**: [Plotly](https://plotly.com/python/)
- **SQL Security & Sanitization**: [SQLParse](https://sqlparse.readthedocs.io/)

## ⚡ Core Features

1. **Executive Sales Dashboard (`app.py`)**:
   - Live KPI cards: Total Store Sales, Total Quantity Sold, Net Profit, Average Ticket Price.
   - Interactive Plotly visualizations for daily sales trends and omnichannel comparison.
   - Top 10 products revenue leaderboard.
   - Dynamic Snowflake connection health badge with latency diagnostics.
   - Active data-source indicator (`SNOWFLAKE_SAMPLE_DATA`).

2. **Ask DataLens (`pages/1_Ask_DataLens.py`)**:
   - Natural language to SQL engine powered by locally hosted **Qwen3-4B** (`http://localhost:11434`).
   - Multi-stage pipeline:
     $$\text{Question} \rightarrow \text{Qwen3-4B} \rightarrow \text{SQL Generation} \rightarrow \text{SQL Validation} \rightarrow \text{Snowflake Execution} \rightarrow \text{Results Table} \rightarrow \text{Plotly Chart} \rightarrow \text{Plain-English Explanation}$$
   - Chain-of-thought inspector to review model reasoning.
   - Dynamic Plotly chart generation (line for time-series, bar for categories, metrics for scalar totals).

3. **Sales & Channel Analytics (`pages/2_Sales_Analytics.py`)**:
   - Omnichannel comparison: Store Sales vs. Web Sales vs. Catalog Sales.
   - Channel market share donut chart and revenue breakdown.
   - 7-day moving average trendline for store sales.

4. **Product Analysis (`pages/3_Product_Analysis.py`)**:
   - Configurable product leaderboard ($N=5$ to $25$).
   - Category performance and profitability charts.

5. **Snowflake Data Explorer (`pages/4_Data_Explorer.py`)**:
   - Dynamic schema inspector fetching live column structures from `INFORMATION_SCHEMA`.
   - Table preview for sample data.
   - Safe SQL Console for running custom queries with safety guardrails and CSV export.

## 🛡️ SQL Safety & Security Engine

All queries—whether generated by Qwen3-4B or entered manually—pass through [`services/sql_validator.py`](file:///services/sql_validator.py):
- **Read-Only Enforcement**: Permits only `SELECT` and `WITH ... SELECT` queries.
- **Statement Guard**: Strictly forbids semicolons separating multiple statements to prevent SQL injection.
- **Forbidden Keyword Blocker**: Rejects `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, `TRUNCATE`, `CREATE`, `REPLACE`, `MERGE`, `GRANT`, `REVOKE`, `COPY`, `EXECUTE`, etc.
- **Table Allowlist**: Access is restricted strictly to approved TPC-DS tables (`STORE_SALES`, `WEB_SALES`, `CATALOG_SALES`, `ITEM`, `CUSTOMER`, `DATE_DIM`).
- **Automatic Limit Enforcement**: Automatically appends `LIMIT 100` if not present (clamps limits $> 500$).
- **Partition Filtering**: Prompts and pre-built queries filter on `date_dim.d_year` to avoid scanning multi-terabyte unpartitioned tables.
- **Zero Synthetic Fallback**: If credentials are missing or connection fails, a setup guide is displayed; mock or synthetic data is never substituted.

## 🚀 Setup & Execution Guide

### 1. Prerequisites
- Python 3.10+
- [Ollama](https://ollama.ai/) installed locally with the `qwen3:4b` model:
  ```bash
  ollama run qwen3:4b
  ```
- A Snowflake account with access to `SNOWFLAKE_SAMPLE_DATA`.

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure Snowflake Credentials
DataLens Live reads credentials securely from `.streamlit/secrets.toml`. Credentials are never hardcoded or tracked in Git.

1. Copy the example configuration template:
   ```bash
   cp .streamlit/secrets.toml.example .streamlit/secrets.toml
   ```
2. Open `.streamlit/secrets.toml` and configure your credentials:
   ```toml
   [snowflake]
   account = "YOUR_ACCOUNT_IDENTIFIER"  # e.g. "xy12345.us-east-1" or "myorg-myaccount"
   user = "YOUR_SNOWFLAKE_USERNAME"     # Note: Use your LOGIN_NAME (may be your email or username)
   password = "YOUR_SNOWFLAKE_PASSWORD"
   warehouse = "COMPUTE_WH"
   database = "SNOWFLAKE_SAMPLE_DATA"
   schema = "TPCDS_SF10TCL"             # Or TPCDS_SF100TCL
   role = "ACCOUNTADMIN"                # Optional
   ```

#### 🌐 Single Sign-On (SSO) / Browser Authentication
If you signed up with **"Sign in with Google"**, Microsoft SSO, or have Multi-Factor Authentication (MFA) enrolled on your Snowflake account, add the `authenticator` setting:
```toml
authenticator = "externalbrowser"
```
This opens your default web browser for a single-click login, automatically returning the session token to DataLens.

### 4. Verify Connection
Run the connection diagnostic tool:
```bash
python diagnose_snowflake.py
```
This tests `SELECT CURRENT_VERSION()` and validates your parameters without exposing passwords.

### 5. Launch DataLens Live
```bash
streamlit run app.py
```
The application will launch in your browser at `http://localhost:8501`.
